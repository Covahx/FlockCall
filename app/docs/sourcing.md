# Audio Sourcing Log

Record one entry per clip bundled in `assets/audio/`. Required fields: filename, source URL, recordist, license, date downloaded. This file ships with the app and provides attribution.

## Template

```
- file: contact_01.m4a
  source: https://xeno-canto.org/XXXXXX
  recordist: Name Here
  license: CC BY-NC-SA 4.0
  downloaded: 2026-05-11
  notes: juvenile contact call, trimmed to 1.4s
```
